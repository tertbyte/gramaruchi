# GRAMARUCHI

A premium minimal ecommerce concept for traditional South Indian pantry products.

## Products
- Ullundhu Kazhji Mix — ₹499 / 500g
- Roasted Salt — ₹299 / 250g

## Features
- Responsive premium storefront
- Minimal editorial design
- Product cards
- Working client-side bag/cart
- Demo checkout flow
- Story and journal sections
- Mobile-friendly layout

## Run locally
Open `index.html` in a browser, or deploy the repository to Vercel, GitHub Pages, Netlify, etc.
